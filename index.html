🤖 বট আচরণ (config.json জেনারেটর)

এখানে টগল করলে নিচে ঠিক সেই সেটিংসসহ একটা JSON স্নিপেট তৈরি হয়ে যাবে — সেটা কপি করে আপনার বট প্যানেলের config.json-এ পেস্ট করুন। এখানে টগল করাটা নিজে থেকে লাইভ বটকে বদলায় না (এই ওয়েবসাইট আর Render বট আলাদা সার্ভার) — এটা শুধু সঠিক JSON বানিয়ে দেয়, যাতে ম্যানুয়ালি ভুল না হয়। 

টগল করলে এখানে config.json স্নিপেট আসবে…

⚠️ গুরুত্বপূর্ণ সীমাবদ্ধতা (সততার সাথে জানানো)

এই সেটিংস পেজ থেকে Vercel-এর আসল Environment Variable বা সিক্রেট কী পরিবর্তন করা সম্ভব না — সেটা করতে হয় Vercel Dashboard → Settings → Environment Variables থেকে, সরাসরি। এখানে যা সেভ হয় (থিম, নাম) তা শুধু এই ব্রাউজারে (localStorage), অন্য ডিভাইসে দেখাবে না। "নতুন API যোগ" পেজের এন্ট্রিগুলোও একইভাবে শুধু এই ব্রাউজারে সেভ থাকে — সবার জন্য স্থায়ীভাবে রাখতে চাইলে একটা ডেটাবেজ (যেমন আপনার বটের MongoDB Atlas) যোগ করতে হবে, চাইলে সেটাও পরে বানিয়ে দিতে পারি।
